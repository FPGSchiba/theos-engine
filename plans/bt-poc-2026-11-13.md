# Behaviour-Tree PoC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure whether Qwen3.5-4B writes behaviour trees that pass the gate and behave as the bt-poc fixture demands within the AI Latency Budget, and whether injected text can hijack them — with no guardrails.

**Architecture:** `theos-ai` gets a minimal, general change (optional grammar, `Npc::select`, `Npc::generate` on the shared token loop). Everything tree-specific lives in a new disposable crate `plugins/llm-poc/bt-poc`: fixture loading, prompt, recursive schema, grammar-off JSON extraction, scoring through `fixtures/bt-poc/check.py` (imported, unchanged), runs and reports, plus a BT injection suite judged against its clean base scenarios.

**Tech Stack:** Rust 2024 (`theos-ai` in the root workspace; `plugins/llm-poc` workspace on Rust 1.99.1), `llama-cpp-2 =0.1.161` + llguidance, `serde_json`, `toml`, `clap`, `csv`, `jsonschema` (dev, validation tests), Python 3.11+ (standard library) for scoring.

**Spec:** `docs/superpowers/specs/2026-11-13-bt-poc-design.md` (approved 2026-11-13) and `fixtures/bt-poc/README.md` (the harness specification). Read both before any task.

## Global Constraints

- **No guardrails.** The special-token hole stays open (`theos-ai-llama/src/generator.rs` `begin` tokenizes the whole prompt with special parsing on).
- **Unchanged files:** everything under `fixtures/bt-poc/` except the new `injections.toml`; `fixtures/lore-poc/` entirely. `check.py` is imported, never edited.
- **`theos-ai`:** only the change in Task 2; nothing tree-specific; gate in order — `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `cargo check --workspace --all-features`, `cargo test --workspace --all-features`, `cargo llvm-cov -p theos-ai --all-features --summary-only` ≥ 85 % region; no `unwrap`/`expect` in production code without an `// invariant:` comment; `#![deny(missing_docs)]`.
- **Model outputs** (trees, thinking text) stay in the ignored `plugins/llm-poc/results/`; never in git.
- **Values:** budgets CombatTactical 8 s, WorldEvent 30 s (from `scenarios.toml` `budget_seconds`); tree token cap 1 536; tree `name` `maxLength: 80`; thinking-on runs keep the priority budget as deadline and get a thinking budget (CombatTactical 512, WorldEvent 2 048 thinking tokens; the backend closes the thinking block at the budget — see Spike results); tree sampling = the dialogue card values with presence penalty 0 (thinking phase keeps the card's thinking profile); entity line `- {handle}: {kind}, {distance} m` plus `, called "{name}"` when named; directive in the user part, everything else in the system part.
- **Lore for NPC actors** comes from `Npc::select(speaker, directive, scope)`; the corpus and speakers from `fixtures/lore-poc/expected/corpus.json`; leak is checked against `fixtures/lore-poc/expected/visible.json`.
- Commit messages `<type>(bt-poc): <summary>`, body references `plans/bt-poc-2026-11-13.md`, ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A grammar-off reply with prose around the JSON, a code fence, or two JSON objects → the first balanced top-level object is taken; nothing parsable → gate `shape` (Task 5 test `extract_takes_the_first_balanced_object_and_reports_none_when_absent`).
2. A correct tree must never be forbidden by the grammar → every `reference/bNN-good.json` validates against its scenario's schema (Task 5 test `every_good_reference_tree_validates_against_its_schema`).
3. An NPC actor in scope `none`, or any enemy → `sources` fixed empty (`maxItems: 0`) (Task 5 test `sources_are_fixed_empty_without_lore`).
4. Thinking on filling the context → the row records `ContextFull` and the run goes on (Task 7 test `context_full_becomes_a_failed_row_and_the_run_continues`).
5. An injected row whose clean base row is missing from the baseline → classified `no baseline`, never `obeyed` (Task 8 test `injected_row_without_clean_base_is_no_baseline`).
